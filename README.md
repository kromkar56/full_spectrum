# Full Spectrum — Spectra 2026 Group Build Event 🎓⏱️
## Project: CampusDeadline

> **CampusDeadline turns scattered personal and group academic deadlines into one early-warning system that tells students what is coming, what is risky, and what they should do next.**

---

## 📋 Required Deliverables (Rulebook Compliance)

This repository contains all 6 required stages for the Full Spectrum build event:

1. **Solution Stage:** [`solution.md`](./solution.md)  
   *Core pitch, academic problem breakdown, and early-warning architecture.*

2. **User Flow Stage:** [`user-flow.md`](./user-flow.md)  
   *Step-by-step user journey, Mermaid state diagram, and screen interaction matrix.*

3. **Design Stage:** Design files and implementation in [`campus-deadline/src/index.css`](./campus-deadline/src/index.css)  
   *Google Stitch minimal student productivity design system with warm sandstone, cream surfaces, terracotta accents, and dark theme.*

4. **Idea Source Stage:** [`idea-origin.md`](./idea-origin.md)  
   *Genesis of the project, mid-semester collision crisis, classmate interview validation, and ethical non-medical framing.*

5. **Build Stage:** Working code in [`campus-deadline/`](./campus-deadline/)  
   *Production-ready React 19 + Vite application with centralized state, automated collision detection, academic load radar, smart priority, and streak engine.*

6. **Documentation Stage:** [`documentation.md`](./documentation.md)  
   *Complete system documentation, data models, algorithm specifications, how to run, and judging Q&A cheat sheet.*

## 🚀 Quick Start

```bash
# Navigate to application
cd campus-deadline

# Install dependencies
npm install

# Run development server
npm run dev

# Run automated algorithmic tests
node test_engine.js

# Build production bundle
npm run build
```
